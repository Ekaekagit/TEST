# Сценарий для тренировки @-упоминаний

Этот набор связанных файлов создан, чтобы потренироваться ссылаться на файлы
через `@`-упоминания в Claude Code. Файлы намеренно ссылаются друг на друга,
чтобы было естественно упоминать сразу несколько.

## Структура

```
mentions-demo/
├── README.md            ← вы здесь
├── config.json          ← настройки приложения
├── src/
│   ├── index.js         ← точка входа, связывает всё вместе
│   ├── storage.js       ← слой хранения задач
│   └── tasks.js         ← бизнес-логика задач
└── docs/
    └── architecture.md  ← описание архитектуры
```

## Как пробовать @-упоминания

В приглашении Claude Code наберите `@` и начните печатать путь — появится
автодополнение файлов. Примеры запросов, которые можно попробовать:

- «Объясни, что делает @mentions-demo/src/tasks.js»
- «Сравни @mentions-demo/src/storage.js и @mentions-demo/src/tasks.js»
- «Проверь, что @mentions-demo/src/index.js правильно использует
  настройки из @mentions-demo/config.json»
- «Обнови @mentions-demo/docs/architecture.md по коду в
  @mentions-demo/src/»

Можно упоминать и целые папки: `@mentions-demo/src/`.

## Что делает пример

Мини-менеджер задач в памяти: добавляет, отмечает выполненными и фильтрует
задачи. Логика — в @mentions-demo/src/tasks.js, хранение —
в @mentions-demo/src/storage.js, всё вместе собирается в
@mentions-demo/src/index.js.
