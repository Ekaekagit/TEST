# Архитектура mentions-demo

Маленький менеджер задач из трёх слоёв. Каждый слой живёт в своём файле,
чтобы удобно было ссылаться на них по отдельности через @-упоминания.

## Слои

1. **Настройки** — `../config.json`
   Лимиты, приоритеты и параметры хранения. Читается в
   `../src/tasks.js` и `../src/index.js`.

2. **Хранение** — `../src/storage.js`
   Класс `MemoryStorage`: хранит задачи в `Map` в памяти. Ничего не знает
   о бизнес-правилах.

3. **Бизнес-логика** — `../src/tasks.js`
   Класс `TaskManager`: валидирует приоритеты, добавляет, завершает и
   фильтрует задачи. Делегирует хранение слою `MemoryStorage`.

4. **Точка входа** — `../src/index.js`
   Собирает всё вместе и демонстрирует работу.

## Поток данных

```
index.js  ──создаёт──▶  TaskManager (tasks.js)
                              │
                              ├─ читает ─▶ config.json
                              └─ хранит ─▶ MemoryStorage (storage.js)
```

## Как проверить

```bash
node mentions-demo/src/index.js
```
